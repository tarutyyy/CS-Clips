# ハッシュテーブルのメモ（テスト用の仮メモ）

※ /make-video の動作確認のために Claude が作った仮のメモ。実際の学習メモではない。
※ 検証用に、わざと 1 か所だけ誤りを入れてある（スキルが指摘できるかを見るため）。

- 配列は、番号（添字）が分かれば一瞬でその要素にたどり着ける
- ハッシュテーブルは、キー（文字列など）をハッシュ関数で数に変えて、その数を添字にする
- たとえば "apple" → ハッシュ関数 → 3 なら、3 番の箱に入れる。探すときも同じ計算をして、3 番の箱を見る
- データが何件あっても、計算して箱を見るだけなので、平均して一定時間で探せる
- ハッシュ関数が優秀なら、異なるキーが同じ箱に当たる「衝突」は絶対に起きない。だから常に 1 回で見つかる
- 箱の数が足りなくなってきたら、箱を増やして入れ直す（リハッシュ）
